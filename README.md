# Elemental Hand FX 🔥❄️⚡

An interactive web-based visual effects project that uses real-time hand tracking to generate stunning elemental animations like fire, ice, lightning, plasma, and dark matter.

Built using MediaPipe Hands and HTML5 Canvas, this project allows users to control effects dynamically using hand gestures captured through a webcam.

---

## ✨ Features

- 🔥 Fire & Ice dual-hand effects  
- ⚡ Lightning generation with dynamic intensity  
- 🔴🔵 Force / Frost mode  
- 🌀 Plasma vortex animations  
- 🌌 Dark matter warp effects  
- 🤏 Gesture controls (pinch, open palm, fist)  
- 👏 Clap detection for shockwaves  
- 🎨 Smooth particle systems and trails  

---

## 🎮 Controls

| Key | Mode |
|-----|------|
| 1 | Fire / Ice |
| 2 | Lightning |
| 3 | Red / Blue |
| 4 | Plasma |
| 5 | Dark Matter |

## 🧠 Gestures

- ✋ Open Palm → Activate energy  
- ✊ Fist → Surge burst  
- 🤏 Pinch → Draw energy trails  
- 👏 Clap → Trigger shockwave

1. Clone the repository

3. Allow camera access
